# Решения 0.2.0

- Стек существующего проекта сохранён; исправление не требует перезаписи Android-оболочки.
- Автоанализ по умолчанию, ручной ввод — запасной и для этикетки. Без ключа обычный dev не притворяется распознаванием; явный dev:demo использует фиксированные данные.
- Пищевые значения даёт модель как оценку; итог порций и масштабирование считают типизированные функции, а не LLM. Точность данных модели не обещается.
- Anthropic модели claude-haiku-5-5 и claude-sonnet-5-5 сверены с официальным каталогом 2026-10-24. Доступность аккаунту всё равно требует живой проверки. OpenAI/Gemini модели задаются владельцем, не угадываются.
- Ключи только серверные; JWT/коддоступа/квоты ограничивают личный тест. Постоянный распределённый budgetstore остаётся обязательным до публичного релиза.
- Одна попытка исправления JSON, без бесконтрольных сетевых повторов. Нет фоновых платных запросов при правке граммов.
- Фото не сохраняются. Кеш оценки локальный 24 ч/50 записей. Уточнение сохранённого блюда без повторного фото опирается на текстовое описание, не на старое изображение.
- Полная offline-перезагрузка браузера не гарантируется: Service Worker ещё нет. Native-ресурсы упакованы, но Android сборка не проверена.
