# Архитектура

```text
app (React / Dexie / Capacitor)
  ├── core/platform: web | native
  ├── core/nutrition: локальная арифметика
  └── core/ai: пока только проверка /health
              ↓ HTTPS (Android), Vite proxy (dev)
server (Fastify, Helmet, CORS, базовый rate limit)
  └── /health
packages/shared (zod, версия и общие типы)
```

Будущая архитектура: сервер будет stateless проксировать ограниченные задачи к провайдеру; API-ключи только на сервере. Сейчас провайдеров нет, платных запросов нет. Ручные записи и вода не отправляются на сервер.

`packages/shared` собирается перед сервером. Клиент Vite импортирует исходник по alias; Node использует dist. `npm run dev` запускает одновременно Vite и tsx: после свежего clone сначала выполните `npm run build -w @racionika/shared` (в dev-скрипте это делается автоматически).

При расширении БД: version(2) и миграция, не reset. При расширении API: строгая валидация на обеих границах. Photo consent должен говорить отдельно о хранении приложением и о политике retention провайдера — нельзя гарантировать отсутствие хранения третьей стороной без соответствующих условий.
