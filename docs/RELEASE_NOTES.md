# Удобный дневник: поиск, порции и напоминания

## Что нового

- Быстрый переход между днями, кнопка «Сегодня» и календарь с отметками записей.
- Знакомые продукты выше в поиске, сокращения, бренды и близкие опечатки.
- Вид продукта рядом с результатом, жирность и производитель в названии.
- Проверенные меры USDA: ложки, US cup и яйца в штуках; последняя порция по нажатию.
- «Добавить и продолжить» — несколько продуктов без закрытия поиска.
- Действия уведомлений: «Я уже поел», «Через 30 минут», «Записать еду».
- Обновлена инструкция по использованию.

«Я уже поел» отменяет повтор, но не создаёт записи и калории. Меры порций доступны только там, где есть исходный вес; US cup не равен любому домашнему стакану. Поиск по 20 000 продуктов работает без интернета, для распознавания фото нужен интернет.
