# Проверки 0.3.0

Linux sandbox, Node 24.22.1, системный Chromium через Playwright. Проверяется код и локальная демонстрационная сборка, не весь исходный продукт и не точность ИИ.

## Автоматические проверки

- format:check, lint без предупреждений, typecheck трёх workspaces.
- npm test: **101 Vitest-тест в 11 файлах + 4 Node-теста конфигурации APK**.
- npm run build: shared + приложение + сервер.
- **18 E2E в dev-режиме и те же 18 на собранном приложении**, прогоны последовательно, на отдельных чистых тестовых серверах.
- npm audit --omit=dev: 0 найденных уязвимостей. Это не аудит dev-зависимостей или полный пентест.
- Сборка интерфейса с публичным HTTPS API URL и cap sync android — успешно, обнаружены 10 плагинов.

Покрыты формулы/ограничения личного плана, несовершеннолетние/особые состояния/недостаточный целевой вес, согласие v2 и отзыв, повреждённый профиль, расписание 5 ч и часы сна, переход бодрствования через полночь, 7 мотивационных фраз по дням недели, проверка JSON и отсутствие переноса токенов/согласия. Подставной Android API проверяет отказ разрешения без удаления старых будильников, замену только своих ID, восстановление прежнего расписания при ошибке и отключение без нового запроса разрешения. Эти тесты не заменяют Android-устройство.

E2E: старые сценарии дневника/воды/фото/текста/ошибок/кеша/навигации + чистый первый вход, норма и сохранение, профиль/цель в запросе наставника, отсутствие повторных галочек и кодов, блокировка новых запросов без согласия, отзыв после перезапуска, preview времени напоминаний, импорт старого JSON v2 дважды без дублей и сохранение веса.

Платные запросы в тестах не выполняются. Для форматов провайдеров используются подставные ответы; демо не является распознаванием еды. Пользователь ранее сообщил, что настоящая фотооценка работает в своей сборке.

## Визуальная проверка

Мобильные 390 px / светлая тема и 360 px / тёмная тема: первый вход, рассчитанный план/согласие, главная с личной целью и водой, настройки/тихие часы, профиль/приватность/резервные копии, вес, наставник, простой результат. Рендер локального HTML через Chromium, каждый снимок осмотрен отдельно. Исправлены сжатое поле своего объёма воды и тесные отступы формы веса/расписания. Горизонтального переполнения и ошибок страницы в проверенных состояниях нет. Это локальная проверка интерфейса, не публикация веб-версии.

## Что обязательно проверить на телефоне после Actions

1. Установка/обновление 0.3.0, versionCode 4. До любой переустановки — экспорт старого JSON; стабильная debug/release-подпись пока не настроена.
2. Первый вход с реальными данными, сохранение цели, отзыв согласия, офлайн-дневник.
3. После deploy Render /health version:0.3.0 и /v1/config access_code_required:false. Настоящие фото/текст/чат с AnyModel, без кода сервера.
4. Разрешение/отказ уведомлений, отдельное разрешение точных будильников, изменение сна/интервала, отключение каналов.
5. Доставка с заблокированным экраном, закрытым приложением, после перезагрузки, Doze/экономия энергии, часовой пояс. Плагин объявляет boot receiver и сохраняет расписание, но это не подтверждение работы на каждой модели Android.
6. Нажатие уведомления открывает нужный экран. На сон уведомления не назначаются, но для абсолютной тишины при задержках ОС нужен также режим «Не беспокоить».
7. Экспорт/импорт реальной копии, проверка дневника/воды/веса, не удалять приложение до проверки резервной копии.

Android SDK в sandbox отсутствует: cap sync проверяет подготовку проекта, не Gradle/APK/установку. Новые GitHub Actions, Render deploy, нативные разрешения, перезагрузка и работа AnyModel с ключом пользователя здесь не подтверждены. Не проверены нагрузка/пентест и полная матрица миграций. План оставшейся работы — ROADMAP.md; ограничения — STATUS.md.
