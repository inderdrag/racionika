# Название и визуальный фундамент

10 вариантов: Рационика / Racionika; Едалия / Edalia; ПорцияУм / Porcium; Тарелли / Tarelli; Нутривея / Nutriveya; ЛистЕды / Listedy; ЕдаЛад / Edalad; ПорцияДня / Porciadnya; ВкусРитм / Vkusritm; Сытолад / Sytolad.

Выбрана **Рационика / Racionika**: ассоциация с рационом, без обещания медицинской точности, пригодно для русского UI и латинского имени репозитория. Поиск «Рационика приложение питание» и «Racionika nutrition app» не дал подтверждённого точного совпадения в просмотренной выдаче. Это ограниченная проверка, не юридическое заключение и не проверка реестров товарных знаков; перед публичным запуском нужен отдельный trademark/store search.

- Launcher: Рационика.
- Android: com.inderdrag.racionika.
- Repo: racionika. Render: racionika-api.
- Планируемый APK: Racionika-v{version}.apk (на этом этапе ещё не создаётся).
- Иконка: тарелка, лист и небольшая искра. Исходник: branding/icon.svg. Android-векторы — первоначальные, не финальные production assets.
- Цвета/отступы/радиусы: app/src/tokens.css. Зелёно-бирюзовый акцент, отдельные цвета БЖУ/воды. Системная тёмная тема. Локальный Manrope с кириллицей; лицензия OFL в docs/LICENSES.md.
