# Офлайн-база продуктов

## Как пользоваться

**Дневник → Добавить еду**: ввод названия ищет только на телефоне.
Встроено **12 632 продукта и варианта** USDA. Камера справа — отдельное
распознавание ИИ с интернетом. Интерфейс поиска не усложняется.

Выберите продукт, массу и приём пищи. КБЖУ пересчитываются локально.
Варианты приготовления хранятся отдельно: сырая крупа не подменяется кашей.
«Вид не уточнён» означает, что источник не указал состояние явно;
приложение не выдумывает коэффициенты приготовления.

Поиск работает по русскому названию, исходному английскому описанию,
ID USDA и бытовым синонимам. Первые 20 результатов выводятся сразу,
остальные — по «Показать ещё». Исходные 505 записей остаются приоритетными
среди сопоставимых результатов. Их ID и КБЖУ не меняются: существующие записи
дневника, избранное и JSON-копии не требуют миграции.

## Источники и ограничения

U.S. Department of Agriculture, Agricultural Research Service, FoodData Central:

- **SR Legacy, April 2018** — финальный исторический выпуск.
- **FNDDS 2021–2023, опубликован в октябре 2024** — продукты, напитки и
  составные блюда, используемые в исследовании питания.
- Загрузка: https://fdc.nal.usda.gov/download-datasets
- Описание типов данных: https://fdc.nal.usda.gov/faq/
- Лицензия **CC0 1.0 Universal**, данные в общественном достоянии:
  https://fdc.nal.usda.gov/api-guide

Это не база всех российских торговых марок и не лабораторная проверка
порции пользователя. Рецептуры, производители и состав могут отличаться.
FNDDS включает типовые блюда и неуточнённые варианты; проверяйте описание.
Не добавляем брендовые записи без полных КБЖУ просто для увеличения счётчика.

**Все четыре нутриента каждой записи сверены с исходным набором**:
ккал и граммы белков, жиров и углеводов на 100 г. Данные не заменяются
формулой 4/4/9 и не дополняются придуманными значениями. Неполные записи,
значения за пределами схемы и записи детского питания исключены.
Одинаковые исходные ID и повторяющиеся описания не размножаются.
Разные реальные записи источника с одинаковым переводом различаются ID.
Статистика отбора — в `extended-manifest.json`.

**Перевод названий не равен проверке нутриентов.** Первые 505 названий
сохранены из прежней локализованной выборки. Названия остальных 12 127
записей переведены автоматически (Argos English–Russian 1.9), не прошли
полную ручную языковую/диетологическую проверку и могут быть неточными.
Состояние продукта определяется отдельно по исходному описанию.
Оригинал, выпуск, ID и ссылка всегда доступны в раскрываемом «Источник: USDA».
Там же указан автоматический перевод для записей расширения.
Модель перевода не входит в APK и не вызывается при поиске.

## Воспроизводимость и сборка

Исходные 505 записей: `usda.json`, `scripts/catalog/selection.json`,
`scripts/catalog/manifest.json`. Расширение хранится компактными gzip/base64
частями в `scripts/catalog/packed/`, с SHA-256 каждой части, сжатого и
распакованного содержимого в `scripts/catalog/extended-manifest.json`.
Это данные, не исполняемый код.

`npm ci` автоматически проверяет контрольные суммы и материализует
`app/src/core/catalog/generated.json`. Повторить без интернета:

```sh
node scripts/catalog/unpack.mjs
```

Полученный файл игнорируется Git и Prettier; проверенный материализованный
набор включается Vite в APK. На телефоне не нужны скачивание базы, ключ API,
модель перевода или распаковка gzip. После установки APK поиск работает
без сети. При повреждении исходных частей сборка останавливается.

### Независимая сверка с USDA

1. Скачайте официальные SR Legacy CSV ZIP и FNDDS JSON ZIP по ссылкам из
   `extended-manifest.json` и проверьте SHA-256 архивов.
2. Распакуйте SR Legacy CSV в отдельную папку. FNDDS ZIP можно не распаковывать.
3. Запустите:

```sh
python scripts/catalog/verify-extended.py /path/to/SR-CSV /path/to/FNDDS.zip
```

Сверяются ID, полные оригинальные описания, единицы и все 50 528 значений
нутриентов. Скрипт не оценивает качество машинного перевода.
Исходную выборку также можно отдельно сверить прежним `verify-usda.py`.

## Проверки

- Схема всех записей, уникальные ID и названия, исходные калории и варианты.
- Поиск русского/английского названия, ID, синонимы и ограниченный кеш.
- Неизменность исходных записей, источники в дневнике, избранном и JSON.
- Сборка на чистой установке, контрольные суммы и отказ при повреждении частей.
- Поиск без интернета, пагинация и добавление нового продукта из расширения.

Прямой внешней загрузки базы при вводе запроса нет. Существующий отдельный
справочник Open Food Facts не объединяется с USDA и не используется
для достижения указанного количества записей.
