# Офлайн-база продуктов

## Как пользоваться

**Дневник → Добавить еду**: ввод названия ищет только на телефоне.
Встроено **20 000 продуктов и вариантов**: 12 632 USDA и 7 368 продуктов
российского рынка из Open Food Facts. Камера справа — отдельное
распознавание ИИ с интернетом. Интерфейс поиска не усложняется.

Выберите продукт, массу и приём пищи. КБЖУ пересчитываются локально.
Варианты приготовления хранятся отдельно: сырая крупа не подменяется кашей.
«Вид не уточнён» означает, что источник не указал состояние явно;
приложение не выдумывает коэффициенты приготовления.

Поиск работает по русскому названию, исходному английскому описанию,
ID USDA и бытовым синонимам. Первые 20 результатов выводятся сразу,
остальные — по «Показать ещё». Исходные 505 записей остаются приоритетными
среди сопоставимых результатов. Их ID и КБЖУ не меняются: существующие записи
дневника, избранное и JSON-копии не требуют миграции.

## Источники и ограничения

U.S. Department of Agriculture, Agricultural Research Service, FoodData Central:

- **SR Legacy, April 2018** — финальный исторический выпуск.
- **FNDDS 2021–2023, опубликован в октябре 2024** — продукты, напитки и
  составные блюда, используемые в исследовании питания.
- Загрузка: https://fdc.nal.usda.gov/download-datasets
- Описание типов данных: https://fdc.nal.usda.gov/faq/
- Лицензия **CC0 1.0 Universal**, данные в общественном достоянии:
  https://fdc.nal.usda.gov/api-guide

Это не база всех российских торговых марок и не лабораторная проверка
порции пользователя. Рецептуры, производители и состав могут отличаться.
FNDDS включает типовые блюда и неуточнённые варианты; проверяйте описание.
Не добавляем записи без полных КБЖУ просто для увеличения счётчика.

**Все четыре нутриента каждой записи USDA сверены с исходным набором**:
ккал и граммы белков, жиров и углеводов на 100 г. Данные не заменяются
формулой 4/4/9 и не дополняются придуманными значениями. Неполные записи,
значения за пределами схемы и записи детского питания исключены.
Одинаковые исходные ID и повторяющиеся описания не размножаются.
Разные реальные записи источника с одинаковым переводом различаются ID.
Статистика отбора — в `extended-manifest.json`.

**Перевод названий не равен проверке нутриентов.** Первые 505 названий
сохранены из прежней локализованной выборки. Названия остальных 12 127
записей переведены автоматически (Argos English–Russian 1.9), не прошли
полную ручную языковую/диетологическую проверку и могут быть неточными.
Состояние продукта определяется отдельно по исходному описанию.
Оригинал, выпуск, ID и ссылка всегда доступны в раскрываемом «Источник: USDA».
Там же указан автоматический перевод для записей расширения. Типичные буквальные
ошибки (фарш/«земля», голень/«барабанная палочка», наггетсы и другие) исправляются
консервативными правилами только при подтверждении исходным английским описанием.
Cottage cheese не переименовывается в российский творог. Исходные 505 названий не меняются.
Модель перевода не входит в APK и не вызывается при поиске.

## Воспроизводимость и сборка

Исходные 505 записей: `usda.json`, `scripts/catalog/selection.json`,
`scripts/catalog/manifest.json`. Расширение хранится компактными gzip/base64
частями в `scripts/catalog/packed/`, с SHA-256 каждой части, сжатого и
распакованного содержимого в `scripts/catalog/extended-manifest.json`.
Это данные, не исполняемый код.

`npm ci` автоматически проверяет контрольные суммы и материализует
`app/src/core/catalog/generated.json` и `generated-ru.json`. Повторить без интернета:

```sh
node scripts/catalog/unpack.mjs
```

Полученный файл игнорируется Git и Prettier; проверенный материализованный
набор включается Vite в APK. На телефоне не нужны скачивание базы, ключ API,
модель перевода или распаковка gzip. После установки APK поиск работает
без сети. При повреждении исходных частей сборка останавливается.

### Независимая сверка с USDA

1. Скачайте официальные SR Legacy CSV ZIP и FNDDS JSON ZIP по ссылкам из
   `extended-manifest.json` и проверьте SHA-256 архивов.
2. Распакуйте SR Legacy CSV в отдельную папку. FNDDS ZIP можно не распаковывать.
3. Запустите:

```sh
python scripts/catalog/verify-extended.py /path/to/SR-CSV /path/to/FNDDS.zip
```

Сверяются ID, полные оригинальные описания, единицы и все 50 528 значений
нутриентов. Скрипт не оценивает качество машинного перевода.
Исходную выборку также можно отдельно сверить прежним `verify-usda.py`.

## Проверки

- Схема всех записей, уникальные ID и названия, исходные калории и варианты.
- Поиск русского/английского названия, ID, синонимы и ограниченный кеш.
- Неизменность исходных записей, источники в дневнике, избранном и JSON.
- Сборка на чистой установке, контрольные суммы и отказ при повреждении частей.
- Поиск без интернета, пагинация и добавление нового продукта из расширения.

Прямой внешней загрузки базы при вводе запроса нет. Обе части включены в APK.
Отдельный внешний поиск Open Food Facts не вызывается при вводе в основную строку поиска.

## Продукты российского рынка — Open Food Facts

**7 368** различных записей по штрихкодам из официального снимка Open Food Facts:
https://huggingface.co/datasets/openfoodfacts/product-database . Ревизия Parquet,
SHA-256 исходной выгрузки, контрольные суммы частей и статистика фильтров —
`ru-manifest.json`. Все отобранные записи имеют тег продажи `en:russia`,
название кириллицей и полные ккал/Б/Ж/У. Это не означает российскую страну
производства или лабораторное подтверждение упаковки.

Есть творог, сметана, гречка, пельмени, борщи, сырники, хлеб и другие привычные
продукты, включая торговые марки. Бренд сохраняется в названии, если не указан
там уже. HTML-сущности очищены, запись процентов и десятичного разделителя
унифицирована. Одинаковые нормализованные название+бренд и повторные штрихкоды
не увеличивают счётчик. Из допустимых записей выбраны 7 368 с приоритетом
обычных продуктов и названных брендов. Не заявляем полный охват магазинов РФ.

КБЖУ точно перенесены из источника, без заполнения пропусков нулями.
Неполные, неправдоподобные и сильно противоречащие БЖУ калории исключены,
но это не доказывает правильность исходной карточки сообщества. Сверяйте упаковку.
Известные объёмные упаковки и жидкие продукты с неясной базой 100 г/100 мл
исключены: миллилитры не приравниваются к граммам. Данные на порцию не выдаются
за данные на 100 г. Детское питание и добавки исключены.

### Отдельная лицензированная часть и доступ к данным

Contains data from Open Food Facts, available under the Open Database License.
База OFF и наша адаптированная выборка — **ODbL 1.0**:
https://opendatacommons.org/licenses/odbl/1-0/ . Содержимое отдельных записей —
**DbCL 1.0**: https://opendatacommons.org/licenses/dbcl/1-0/ .
Условия источника: https://world.openfoodfacts.org/data . Изображения не включены.

Эта часть хранится отдельно от USDA CC0, в `scripts/catalog/ru-packed/`.
Сжатые base64-файлы содержат JSON-данные, не исполняемый код. Утилита
`unpack-ru.mjs` проверяет SHA-256 и восстанавливает машиночитаемые данные
офлайн. Лицензии данных не изменяют MIT-лицензию кода приложения.

Даже без доступа к репозиторию пользователь APK может получить **всю
распространяемую часть OFF**: Профиль → О приложении и лицензии →
«Экспорт открытой базы». JSON содержит все 7 368 записей, оригинальные
описания/ID, преобразованные названия, КБЖУ, источник и ссылки на лицензии.
В этом экспорте нет профиля, дневника, чата или иных личных данных.
Атрибуция и ссылки на OFF/ODbL доступны в поиске, источнике и лицензиях.

### Воспроизведение и независимая сверка

Для обычной сборки нужен только `npm ci`, без Python, DuckDB или сети к OFF.
Следующие шаги нужны лишь для переотбора/аудита исходного снимка:

```sh
pip install duckdb
python scripts/catalog/fetch-ru.py /path/to/off-ru.jsonl
python scripts/catalog/verify-ru.py /path/to/off-ru.jsonl
# Переотбор из той же выгрузки и ревизии, указанной в ru-manifest.json:
python scripts/catalog/select-ru.py /path/to/off-ru.jsonl REVISION_FROM_MANIFEST
node scripts/catalog/unpack.mjs
```

`fetch-ru.py` читает нужные столбцы закреплённого Parquet, фильтрует российский
рынок/русский язык и сортирует выгрузку по штрихкоду. `select-ru.py` применяет
описанные фильтры и сохраняет точные исходные значения float32, не округляя
их до отображения. `verify-ru.py` независимо сравнивает **29 472 значения
КБЖУ**, единицы и исходные описания всех выбранных записей. Полный source
Parquet велик; повторный аудит может потребовать существенного трафика.
