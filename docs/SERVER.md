# Сервер — фаза 0

Единственный маршрут: GET /health → {status:"ok",version:"0.1.0"}. Остальные возвращают 404. Нет регистрации/JWT, нет провайдеров, нет платных запросов.

Запуск: npm run dev:server; PORT по умолчанию 8787, привязка 0.0.0.0. NODE_ENV=production исключает dev origins из CORS.

Безопасность каркаса: Helmet, allowlist CORS, bodyLimit 6 MiB, 60 запросов/мин/IP, выключенные автоматические request logs и redaction известных полей. В production перед /v1 необходимо реализовать все пункты защиты из ТЗ. За reverse proxy текущий trustProxy=false ограничивает адрес непосредственного соединения; это безопасный консервативный старт, но не корректная законченная IP-идентификация Render. Не включайте бездумно trustProxy=true.

Тесты inject проверяют только health/headers/CORS/закрытость API/нейтральные ошибки. Полное покрытие будущих JWT, квот, бюджета, изображений и промптов ещё отсутствует.
