# Расширенный дневник питания

## Использование

Во вкладке **Дневник** записи разделены на Завтрак, Обед, Ужин и Перекус. Для старых и ещё не распределённых записей есть группа «Без категории». У каждой группы показан итог калорий; общий итог дня и БЖУ остаются наверху.

1. Добавьте блюдо по фото, описанию или вручную обычным способом.
2. В его карточке раскройте **Действия → Время и заметка**. Выберите приём пищи, укажите время и при желании заметку (до 1000 символов). Сохраните. Эти поля можно очистить; категория и время необязательны.
3. Для изменения состава или порции нажмите само блюдо. Время, категория и заметка при этом сохраняются.
4. **Действия → В избранное** сохраняет отдельную копию рецепта и порции. Она останется в «Мои блюда → Избранное» даже после удаления исходной записи дня. Изменение исходного блюда не переписывает ранее сохранённое избранное; ненужный вариант можно убрать и сохранить новый.
5. В «Мои блюда → Недавние» показаны последние 20 разных блюд среди 200 последних созданных записей. Одинаковые название/порция/состав объединяются, дата и заметка не создают отдельное блюдо. Разные порции остаются разными вариантами. Удалённые записи не входят в недавние.
6. **Добавить** у избранного или недавнего блюда открывает дату, категорию, время и заметку новой записи. По умолчанию дата — выбранный день дневника, время — текущее местное; старая заметка для повторного добавления не подставляется. Новый запрос к ИИ не нужен. Состав и порция копируются; после добавления их можно изменить нажатием блюда.
7. **Действия → Копировать на дату** создаёт независимую запись с новым ID на указанную дату. Состав, порция, категория, время и заметка подставляются из исходной записи, детали можно изменить до подтверждения. Исходная запись не переносится и не изменяется. Повторное подтверждённое копирование — ещё одна запись, а не замена предыдущей.

На Главной остаётся компактный список дня. Группы и библиотека находятся в Дневнике. Экран результата распознавания содержит выбор приёма пищи сверху, затем продукты, граммы, калории и сохранение. Демозаписи сохраняют пометку ДЕМО и при копировании/добавлении из библиотеки.

## Данные и совместимость

- Всё работает локально на телефоне, в том числе избранное, недавние и копирование без интернета. Распознавание/чат по-прежнему требуют связи с сервером.
- IndexedDB/Dexie v4 явно сохраняет все прежние таблицы и добавляет `favoriteDishes`. Старым записям не выдумываются категория и время.
- Время еды — локальное `HH:mm`, календарная дата хранится отдельно. `createdAt` остаётся временем создания записи и используется для списка недавних.
- JSON-экспорт v4 включает категорию, время, заметку и избранное. Приложение принимает старые резервные копии v1–v3. Старые версии APK могут не принять v4: перед обновлением сохраните старый JSON, а восстановление нового выполняйте актуальным APK.
- Импорт объединяет записи и избранное по ID, а не заменяет всю базу. Профиль, разрешение ИИ и напоминания автоматически не заменяются. В preview показано число избранных блюд.
- Удаление всех локальных данных очищает и избранное. Обычное удаление блюда дня его не очищает.
- Облачная синхронизация и аккаунт этим изменением не добавляются. Постоянная подпись APK и существующий release workflow не меняются.

## Проверка

Проверяются: четыре категории и очистка деталей; сохранение после перезагрузки; сохранение метаданных при ручной/ИИ-правке состава; независимое копирование; избранное после удаления исходной записи; повторное добавление без ИИ; недавние без дублей; JSON v4 и старые копии; сохранение всех прежних таблиц при обновлении v3 → v4 и старых записей v1 → v4.

Настоящая установка/обновление APK и поведение Android требуют приёмки на телефоне. Перед установкой сохранить резервную копию, затем собрать Actions → Android APK на main с адресом `https://racionika.onrender.com` и установить подписанный APK поверх старого. Не удалять приложение и не очищать его данные ради обновления.

- ESLint, TypeScript и сборка клиента/сервера — успешно.
- 127 модульных тестов Vitest; 4 Node-теста адреса API и отдельно 7 тестов постоянной подписи APK — успешно.
- 36 E2E-сценариев на dev-клиенте и 36 на собранном клиенте — успешно. Новые UI-сценарии используют фиксированную demo-конфигурацию; тест правки/копирования ИИ-блюда использует фиксированный ответ, не платное распознавание. Старые интеграционные сценарии сохранены. Рабочие лимиты сервера не ослаблены.
- Визуально осмотрены группы еды, пустой дневник, избранное/недавние, формы деталей/копирования/повторного добавления в светлой и тёмной теме на мобильных размерах, а также широкий локальный тестовый экран.
- На физическом телефоне этот релиз пока не проверен; результат успешной сборки/установки APK нужно подтвердить отдельно.

## Уточнение распознавания и целей

- После распознавания **фото и текста** сверху результата выбирается приём пищи: Завтрак, Обед, Ужин или Перекус. Для новой записи выбор обязателен; при правке подставляется сохранённая категория.
- В новых и пересохранённых результатах нет автоматически предположенных масла, соли, сахара и соуса — ни отдельных строк, ни их добавочных калорий/граммов. Старый переключатель автодобавок больше не действует и удалён из Профиля. Явно указанные или достоверно видимые продукты остаются обычными ингредиентами с настоящей пищевой ценностью; приложение не объявляет реально съеденное масло бескалорийным.
- При повторном добавлении из избранного/недавних и копировании старого блюда предполагаемые добавки также исключаются из новой записи и её предпросмотра. Исходные записи дневника не переписываются молча. Для пересчёта старой записи откройте её и сохраните результат заново, предварительно выбрав категорию.
- В Профиле появилась отдельная карточка **«Цель калорий на день»** с кнопкой **«Настроить цель калорий»**. Она ведёт к существующему профилю: параметры тела, активность, снижение/поддержание/набор веса. Расчёт и защитные ограничения прежние; новая норма сохраняется и видна на Главной. Это стартовая оценка, не назначение врача. Для случаев, требующих индивидуального подхода, автоматическая диета по-прежнему не назначается.
- Размеры карточек и общий стиль приложения не менялись.
