# Статус 0.3.0

Целевой продукт — только Android APK. Render публикует API, не сайт. AnyModel подключается серверным ключом; в APK ключа нет.

## Реализовано в коде

- Фото/текст → состав → локальный расчёт КБЖУ. Простой экран результата 0.2.1 сохранён: продукты, граммы, ккал строк и итог, сохранение. БЖУ остаются в расчёте/дневных итогах.
- Первый вход с именем, полом, возрастом, ростом, весом, активностью и целью. Локальный профиль, не облачный аккаунт. Норма/коридор/БЖУ/вода рассчитываются кодом с безопасными ограничениями и доступны офлайн; параметры можно менять.
- Одно явное согласие v2, без повторных галочек в фото/тексте/чате; отзыв в Профиле. Без согласия локальный дневник доступен, новые ИИ-запросы блокируются.
- Автоматическая JWT-регистрация устройства, без поля кода сервера. REQUIRE_ACCESS_CODE=false в Blueprint; старый APP_ACCESS_CODE игнорируется после обновления сервера. Секрет не вшит в APK. Упрощение доступа снижает защиту от чужих расходов: см. SERVER.md.
- Локальные Android-уведомления о еде/воде и ежедневная поддержка: интервалы, сон/пробуждение, отдельные разрешения, переход по нажатию, повторяющиеся будильники, восстановление плагином после загрузки Android. Поддержка — подготовленные фразы, не фоновые запросы ИИ. Интервал начинается от пробуждения каждый день.
- Дневник/вода, свои объёмы воды, вес и история, тема. Наставник получает профиль/цель и дневную сводку; быстрые вопросы без автоотправки.
- Dexie v3 добавляет вес, не удаляя старые таблицы. JSON-экспорт и импорт v1–v3 с проверкой, preview, подтверждаемым слиянием по ID. Повреждённая копия не заменяет дневник. Профиль включён в экспорт, но автоматический импорт профиля, согласия и напоминаний не выполняется; токены/согласие не переносятся.
- Панель «Что пока не готово» удалена; интерфейс показывает реализованные действия. Полная очередь ниже остаётся открытой, а не считается автоматически сделанной.
- Android Actions → подписанный release APK → черновик Release, без автоматической публикации. Постоянный ключ и четыре Secrets настраиваются однократно владельцем по RELEASE.md; SHA-256 закрепляется, versionCode растёт по номеру run (база 1000). Локальный code 5, versionName 0.3.0. До настройки секретов сборка блокируется. Реальная assembleRelease и совместимость двух APK ещё не подтверждены.

## Ограничения и дальнейшая работа

Не реализованы: облачные аккаунты/синхронизация, проверенная локальная база 400–600 продуктов, графики и отчёты 7/30 дней, типы/время еды и избранное/копирование, SSE/вечерний и недельный разбор, CSV, постоянные общие квоты и полноценная авторизация публичного сервиса. Все этапы — ROADMAP.md.

Формула — стартовая оценка, не медицинское назначение. КБЖУ по фото не гарантирует точную массу и скрытые ингредиенты. Уведомления не назначаются на часы сна, но Android/Doze/энергосбережение могут задерживать доставку; строгая тишина также требует режима «Не беспокоить». Фактическая работа уведомлений при закрытом приложении, после перезагрузки и установка нового APK должны быть проверены на телефоне.

Пользователь подтвердил успешную предыдущую APK-сборку и распознавание по фото. Новой APK-сборки/деплоя 0.3.0 это не подтверждает. Android SDK в sandbox отсутствует. Локальные тесты и cap sync не заменяют Gradle/установку. Новую сборку запускайте после CI и deploy Render.

Данные локальны. Ключи старых debug-сборок могли отличаться от нового постоянного; новый ключ не исправит совместимость задним числом: **не удалять приложение без JSON-экспорта**. Импорт старой копии в новой версии проверяется отдельно. Production-зависимости и dev-зависимости — разные области аудита, полного отсутствия уязвимостей не заявляем.
