# Статус 0.2.0

Реализован вертикальный сценарий: описание/фото → серверный ИИ-адаптер → проверенный по схеме состав → локальный расчёт КБЖУ → правка граммов → сохранение/редактирование в дневнике. Есть уточняющие вопросы,lookup нового ингредиента, контролируемые автодобавки, кеш, согласие, лимиты, наставник с локальным чатом и сводкой дня. Демо явно отделено от настоящего ИИ.

Существующий ручной дневник, вода, даты, экспорт сохранены. Dexie v2 добавляет кеш/чат без удаления v1 записей. Данные не синхронизируются между устройствами. Импорт ещё отсутствует.

Проверено локально: TypeScript, сборка, арифметика, контракты,HTTP-защиты и адаптеры с фикстурами; браузерные сценарии описаны в QA.md. Настоящих ключей нет, платных запросов не было. Поэтому реальная доступность моделей, точность распознавания и расход в реальном тарифе НЕ подтверждены.

Не выполнено полное исходное ТЗ: онбординг/профиль/личные цели, проверенная база 400–600 продуктов, вес/графики, готовые напоминания, импорт/отчёты,SSE, богатая dev-панель, постоянные глобальные квоты,Render deploy, подписанный APK и release automation. Нельзя называть эту версию финальным готовым приложением.

## Дополнение AnyModel + Render

Добавлен адаптер AnyModel Chat Completions (текст и изображения) с отдельным серверным ANYMODEL_API_KEY и точными ID моделей из каталога. render.yaml готовит один Web Service: собранный сайт и API на одном домене, JWT_SECRET генерируется, код доступа обязателен. Для браузера отдельный адрес API не нужен; нативной сборке по-прежнему нужен HTTPS API URL. Инструкция — RENDER.md.

Локально: 61 unit/inject-тест и 11 E2E на собранном однодоменном сайте прошли. Это не подтверждение реального распознавания: пользователь ещё должен создать Render-сервис, указать ключ, баланс и совместимые модели.

## Уточнение: только Android APK

По запросу пользователя веб-публикация исключена: render.yaml переключён на SERVE_WEB=false и сборку только shared + server. Подготовлен ручной GitHub workflow Android APK: публичный HTTPS URL сервера задаётся при запуске, ключ AnyModel в сборку не передаётся. Добавлена проверка URL перед локальной/CI сборкой. Workflow ещё не запускался; готового APK, проверки установки на телефон и стабильной release-подписи нет. Ранее описанная однодоменная веб-конфигурация не является целевым вариантом.
