# ИИ-наставник

## Что добавлено

- Обычный чат, меню на завтра, вечерний и недельный разбор. Кнопка подставляет запрос; отправка остаётся явной.
- Питание и вода за последние 7 календарных дней до выбранного дня (не позднее сегодня), реальные измерения веса за 30 дней. Для меню завтра — день после сегодняшней даты, даже если открыт старый дневник.
- Пропущенные дни — `null`, не нули. Средние только по дням с записями. Демоеда исключена; несколько измерений за день заменяются последним, без интерполяции.
- Текущие профиль и цель, последние 10 недемонстрационных сообщений. Текущая цель не выдаётся за историческую. Полные рецепты, фото и заметки дневника в контекст не включаются. До 8 названий блюд выбранного дня, по 64 символа.
- Ответ не меняет профиль, цель и дневник автоматически. Меню и оценки ИИ приблизительны; неполный дневник не означает недоедание.

## Согласие

Существующее согласие `racionika.aiConsent=v2` не расширяется молча. Без нового разрешения наставнику передаётся только выбранный день. Для 7 дней питания и 30 дней веса нужно один раз открыть «Добавить контекст нескольких дней» и нажать «Разрешить контекст 7 дней». Новая регистрация явно включает этот объём в текст согласия.

Разрешение хранится отдельно: `racionika.coachContextConsent=v1`. В Профиле → Разрешения приложения его можно отозвать отдельно от всего ИИ. Редактирование старого профиля не расширяет согласие. Отключение всего ИИ очищает оба разрешения. При удалении локальных данных они тоже удаляются.

## Постепенный ответ

AnyModel получает OpenAI-совместимый запрос `stream: true` в `/v1/chat/completions`. Сервер разбирает настоящие SSE-фрагменты, включая UTF-8 между сетевыми чанками. Это не печатная анимация уже готового ответа. Используется та же модель `MODEL_FAST`, что настроена для наставника; ключ остаётся на Render.

Нативный HTTP в Android буферизует ответы, поэтому приложение не читает SSE напрямую. Вместо этого оно создаёт задачу и получает авторизованный снимок текста каждые 1,8 секунды. Для других провайдеров, не подключённых к этому потоковому адаптеру, ответ появляется целиком (`streamed: false`). Демо-режим по-прежнему явно подписан и использует прежний API.

API:

- `POST /v1/coach/jobs` — создать задачу, один расход чат-лимита;
- `GET /v1/coach/jobs/:id` — прочитать собственную задачу;
- `POST /v1/coach/jobs/:id/cancel` — остановить её;
- прежний `/v1/coach` сохранён для совместимости.

Все три новых маршрута требуют JWT. Чужой идентификатор не позволяет прочитать или отменить задачу. Обычные ограничения запросов и общая конкуренция сохраняются; для частого чтения и отмены есть отдельные лимиты. Чтение не тратит чат-квоту.

## Остановка и хранение

«Остановить ответ», уход со вкладки ИИ, сворачивание приложения, смена дня/профиля или отзыв разрешения прерывают текущий запрос. Сервер передаёт отмену в запрос провайдеру. Уже сгенерированные токены могут быть оплачены; отмена не возвращает их стоимость.

Текст задачи временно находится только в памяти сервера. Постоянная история там не ведётся. Лимиты: не более 64 задач в памяти, 6000 символов ответа, общая конкуренция 8 запросов. Без чтения активная задача останавливается через 20–25 секунд; абсолютный предел 90–95 секунд. Завершённые задачи удаляются через 15–20 секунд. Перезапуск Render удаляет их сразу. Сбой сети при создании задачи без полученного ID также покрывается этим тайм-аутом.

На телефоне полная пара вопрос/ответ сохраняется одной транзакцией только после успешного завершения. Отменённый, оборванный или ошибочный ответ в историю не попадает и не отправляется в следующих запросах. Стрим не повторяется автоматически платным запросом. Фоновых платных разборов и новых push-уведомлений эта доработка не создаёт.

## Проверка на телефоне

1. Дождаться Live последнего коммита в Render и собрать новый Android APK в Actions с прежним URL сервера.
2. Установить поверх прежнего приложения. Открыть ИИ и разрешить контекст, если он нужен.
3. Добавить реальные записи за несколько дней и измерения веса. Запросить «Разбор недели»: пропуски не должны трактоваться как нулевые калории.
4. «Меню на завтра» → Отправить: ответ должен учитывать текущую цель, но не менять её.
5. При достаточно длинном ответе проверить появление частей и «Остановить ответ». Отменённого текста не должно быть после перезапуска.
6. Повторить при пропадании интернета, уходе со вкладки и отзыве разрешения.

Автотесты используют искусственные сетевые ответы, не расходуют баланс AnyModel и не доказывают точность реального меню. Проверка установленного APK и реального потока выбранной модели на телефоне выполняется отдельно владельцем приложения.
