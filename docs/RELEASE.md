# APK и релизы — ещё не настроены

Нет опубликованного APK и подтверждённого успешного запуска на Android. Техническая сборка не является финальным релизом.

CI проверяет только lint/typecheck/unit/e2e/build. Workflow автоматического подписанного release, GitHub Releases, keystore-скрипты и сканирование собранного APK будут реализованы в фазе 9 после безопасного ИИ-прокси.

**СОХРАНИТЕ KEYSTORE В НАДЁЖНОМ МЕСТЕ.** Потеря ключа подписи может сделать невозможным обновление APK поверх установленной версии. Никогда не коммитьте keystore/пароли. Не путайте ключ подписи APK с ключом провайдера ИИ: ИИ-ключ хранится только на сервере.

Будущие GitHub Secrets: ANDROID_KEYSTORE_BASE64, ANDROID_KEYSTORE_PASSWORD, ANDROID_KEY_ALIAS, ANDROID_KEY_PASSWORD. Сейчас вводить их не требуется.

Debug-сборка локально: npm ci → npm run apk:debug (нужны JDK 21 и SDK 36). Она не является стабильной подписью для обновлений между разными машинами.
