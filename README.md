# Рационика / Racionika 0.2.0

Локальный дневник питания с автоматической оценкой КБЖУ по **описанию и 1–3 фото**. React + TypeScript + Dexie, Android-оболочка Capacitor, отдельный Fastify ИИ-прокси.

> Техническая версия, не весь продукт из исходного ТЗ. Автоанализ реализован, но настоящие запросы требуют ключа провайдера на сервере. Без ключа доступен **явно помеченный фиксированный демопример**, не распознавание. Реальная точность не проверена; фото не заменяет весы и этикетку. Render не развёрнут, APK не собран.

## Что работает

- Описание еды или фотографии → ингредиенты, порции, значения на 100 г, диапазоны массы и уточняющие вопросы.
- КБЖУ порции считает код. Правки граммов пересчитываются локально, без нового платного запроса. Добавки масла/сахара/соуса можно отключить или изменить.
- Сохранение и редактирование разбора, вода, даты, ручной резервный ввод, экспорт JSON.
- ИИ-наставник со сводкой выбранного дня и локальной историей.
- Серверные адаптеры Anthropic/OpenAI/Gemini, JWT, код доступа, лимиты, таймауты, Zod-проверка, максимум одна повторная попытка при неверном формате.
- Явное согласие перед отправкой. Фото сжимаются и очищаются от EXIF; приложение не сохраняет исходные фото. Локальный кеш оценок: 24 часа, до 50 записей.

## Открыть на ПК (Windows)

Нужны **Node.js 24 LTS** и Git. Android Studio для браузера не нужна. В PowerShell:

```powershell
git clone https://github.com/inderdrag/racionika.git
cd racionika
npm.cmd ci
npm.cmd run dev:demo
```

Если папка уже клонирована: откройте терминал в ней и выполните `git pull --ff-only`, затем `npm.cmd ci` и `npm.cmd run dev:demo`. Если Git сообщает о ваших изменениях — не удаляйте их принудительно.

Откройте **http://localhost:5173**. Демо проверяет интерфейс и расчёт на одном фиксированном блюде; оно не распознаёт произвольную еду. Остановка — Ctrl+C. На macOS/Linux используйте `npm` вместо `npm.cmd`.

## Включить настоящее определение КБЖУ

1. Остановите демо. Скопируйте `server/.env.example` в `server/.env`.
2. Только в этом локальном файле задайте `ANTHROPIC_API_KEY`, длинный `JWT_SECRET` и личный `APP_ACCESS_CODE`. Генератор секрета и альтернативные провайдеры — в [docs/DEV.md](docs/DEV.md).
3. Оставьте `MOCK_AI=false`. Запустите `npm.cmd run dev`.
4. Откройте localhost:5173 → «Добавить еду» → описание или фото → согласие → «Определить КБЖУ». Если настроен код доступа, введите его в форме. Настоящие запросы оплачиваются по тарифу провайдера.

**Ключ никогда не вставляется в код приложения, VITE-переменные или GitHub.** Для установленного приложения ключ хранит владелец сервера; каждый пользователь не должен заводить свой ключ.

## Ограничения

По фото нельзя гарантировать точные массу, рецепт и скрытое масло. ИИ-значения — оценка, не проверенная пищевая база. Для точного учёта используйте весы и этикетку через ручной ввод. Нельзя обещать медицинскую точность.

Квоты сервера пока в памяти одного процесса и сбрасываются при его перезапуске; для публичного сервиса нужен общий постоянный счётчик и дополнительный edge rate limit. Установите также жёсткий бюджет у ИИ-провайдера. См. [SERVER.md](docs/SERVER.md).

Ещё не готовы: онбординг и личные цели, локальная база 400–600 продуктов, графики прогресса, готовые напоминания, импорт, отчёты, Service Worker, подписанные релизы. Полный статус — [STATUS.md](docs/STATUS.md); проверки — [QA.md](docs/QA.md); развёртывание — [RENDER.md](docs/RENDER.md); исходное [ТЗ](docs/REQUIREMENTS.original.md).
