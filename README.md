# Рационика

**Дневник питания для Android.** Продукты, калории, вода и динамика веса — на вашем телефоне.

## Установка и обновление

1. Откройте [Releases](https://github.com/inderdrag/racionika/releases) и скачайте `app-release.apk` из опубликованного выпуска. Если опубликованных выпусков нет, попросите владельца проекта предоставить подписанный APK: черновики доступны только участникам репозитория с соответствующими правами.
2. Откройте APK на телефоне. При необходимости разрешите установку этому браузеру или файловому менеджеру в настройках Android.
3. При первом запуске заполните профиль и подтвердите согласие на использование ИИ.

Требуется **Android 7.0 или новее** и актуальный Android System WebView. Для камеры и уведомлений приложение запросит системные разрешения.

**Обновляйте поверх установленного приложения, не удаляя его.** Для этого новый APK должен иметь тот же идентификатор приложения и постоянную подпись, а также более высокий номер сборки. Перед обновлением сохраните JSON-копию в Профиле. При ошибке установки не удаляйте приложение: сначала проверьте выпуск у его владельца. Удаление приложения может удалить дневник.

## Как пользоваться

### Добавить продукт

Откройте **Дневник → Добавить еду**. В окне одна поисковая строка с камерой справа:

- **Введите название** — поиск сразу покажет продукты из локальной базы: 505 продуктов и вариантов USDA. Интернет и ИИ для поиска не используются. Выберите продукт, укажите массу и приём пищи, сохраните.
- **Нажмите камеру** — откроется съёмка, без выбора из галереи. Сделайте снимок: разбор начнётся автоматически. Нужен интернет и работающий сервер ИИ. Проверьте продукты и массу, выберите завтрак, обед, ужин или перекус и сохраните блюдо.

Изменение массы пересчитывает калории на устройстве. Масло и соль не добавляются автоматически. Ошибочно определённый компонент можно удалить; состав — уточнить повторным запросом. Фото даёт приблизительную оценку: для точности используйте весы и этикетку.

### Дневник и цели

- Норма калорий рассчитывается по данным профиля; свою цель можно задать в **Профиль → Изменить данные профиля → Расчёт калорий** в пределах ограничений приложения. БЖУ пересчитываются автоматически.
- Круг на Главной и в Дневнике показывает съеденные калории относительно цели.
- В Дневнике доступны время еды, заметки, избранное, недавние блюда и копирование записи на другую дату.
- На Главной можно записать воду. В Прогрессе — вес и графики веса, калорий и воды за 7 или 30 дней. Пересчёт нормы после изменения веса требует подтверждения.
- ИИ-наставник отвечает в прокручиваемом чате: можно запросить меню, вечерний или недельный разбор и остановить ответ. Расширенный контекст нескольких дней включается отдельно.

### Напоминания

В Профиле выберите дни недели, время сна, интервалы или конкретные часы еды и воды. Повтор о незаписанном приёме пищи — через 30 минут, последнее уведомление — ещё через 30 минут; запись еды отменяет повторы. Можно отключать напоминания после выполнения нормы.

Это локальные уведомления Android. Для точного времени может потребоваться отдельное разрешение. Работа после закрытия и перезагрузки зависит также от настроек энергосбережения телефона. После системного «Остановить принудительно» откройте приложение заново. В настройках есть тестовое уведомление.

### Копии и отчёты

В **Профиль → Данные на телефоне** экспортируйте JSON и сохраните его вне приложения. При импорте сначала проверьте сводку и подтвердите восстановление. Профиль и настройки восстанавливаются по выбору; согласия, ключи и расписание уведомлений не переносятся.

CSV предназначен для просмотра отчётов в таблицах, **не для восстановления данных**. JSON-копия содержит личные данные — храните её в безопасном месте. Облачной синхронизации и облачного аккаунта нет.

## Интернет и приватность

Профиль, дневник, избранное, поиск по встроенной базе, расчёт порций и графики работают локально. Для распознавания фото и наставника нужен интернет. На бесплатном Render первый запрос после простоя может выполняться дольше обычного.

После согласия фото и сообщения передаются через сервер приложения провайдеру ИИ (в основной конфигурации — AnyModel). Для наставника передаётся также разрешённый контекст дневника, профиля и веса. Приложение не сохраняет исходные фото в дневнике; перед отправкой снимок пересоздаётся как JPEG. Сервер приложения не сохраняет содержимое запросов; обработка провайдером регулируется его политикой. Согласие можно отозвать в **Профиль → Разрешения приложения**.

Пользователю не нужно вводить API-ключ. Ключ провайдера хранится только на сервере, не внутри APK. Ответы ИИ и расчёты питания — ориентиры, не медицинские назначения.

## Для владельца сервера и выпусков

Интерфейс включён в APK; Render обслуживает API, не публичную веб-версию.

- [Сервер и переменные окружения](docs/SERVER.md)
- [Развёртывание на Render](docs/RENDER.md)
- [Постоянная подпись и выпуск APK](docs/RELEASE.md)
- [Устойчивость загрузки Android-зависимостей](docs/ANDROID_NETWORK_BUILDS.md)

GitHub Actions → **Android APK → Run workflow**: выберите `main` и укажите HTTPS URL своего API в `api_base_url` (**не ключ провайдера**). После успешной сборки и проверки подписи workflow создаёт черновик Release с `app-release.apk`. Перед публикацией проверьте установку и обновление на телефоне; публикация выполняется владельцем вручную.

Сохраните постоянный keystore и пароль в надёжных резервных копиях. Для сборки используются GitHub Secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` и переменная `ANDROID_SIGNING_CERT_SHA256`. Не коммитьте ключи, пароли или файлы `.env`.

## Разработка

Стек: React, TypeScript, Dexie/IndexedDB, Capacitor, Fastify. Нужен **Node.js 24**; для Android — JDK 21 и Android SDK 36.

```sh
git clone https://github.com/inderdrag/racionika.git
cd racionika
npm ci
npm run dev:demo
```

Откройте `http://localhost:5173`. Это локальный предпросмотр: **деморежим возвращает фиксированные примеры, а не распознаёт еду**. Для проверки камеры разрешите браузеру доступ к ней. Публичная веб-версия не выпускается.

Для настоящего ИИ настройте локальный `server/.env` по `server/.env.example` и [инструкции разработчика](docs/DEV.md), отключите деморежим (`MOCK_AI=false`) и запустите `npm run dev`. Серверные секреты не передавайте в клиентские переменные `VITE_*`.

```sh
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e:local
```

На Windows можно использовать `npm.cmd`. Проверки в браузере и подставные ответы не заменяют испытания камеры, уведомлений, энергосбережения и обновления APK на реальном Android.
