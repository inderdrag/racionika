# Changelog

## Постоянная подпись Android APK

- Actions собирает app-release.apk из постоянного PKCS12 в Secrets, без случайного debug fallback. SHA-256 сертификата закреплён repository Variable, готовый APK проверяется apksigner.
- versionCode растёт по GitHub run number; applicationId не меняется. APK остаётся в черновике Releases.
- Помощник Windows создаёт ключ на ПК, безопасно передаёт четыре Secrets через gh stdin, сохраняет локальную копию и не заменяет существующий ключ.
- Однократная настройка владельцем ещё требуется; новый ключ не позволяет обновить старый APK с другим сертификатом. Перед переходом обязателен JSON-экспорт. Реальная Gradle-сборка/обновление проверяются после настройки.

- Dexie v3, проверяемый импорт JSON с preview/подтверждением/слиянием по ID и экспорт без токенов/фото/согласия.
- Удалена панель незавершённых функций, простой результат фото/текста сохранён. Остаток полного ТЗ честно перечислен в STATUS.md.

## APK в черновиках GitHub Releases — 2026-10-24

- После успешной задачи apk отдельная задача draft-release скачивает тот же artifact и создаёт черновик релиза с app-debug.apk. Автоматическая публикация отсутствует.
- Право contents:write дано только задаче черновика; используется штатный GITHUB_TOKEN, новый персональный ключ не нужен. Уникальный тег содержит run ID и attempt; target — точный коммит сборки.
- Существующие успешные сборки автоматически не переносятся: нужен новый запуск обновлённого workflow.
